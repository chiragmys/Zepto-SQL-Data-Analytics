# Zepto SQL Data Analytics

## 📌 Project Overview

This project analyzes Zepto product data using SQL and PostgreSQL to extract useful insights related to product pricing, discounts, inventory, product availability, and categories.

The project includes data exploration, data cleaning, and business-oriented SQL queries.

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- Git
- GitHub

## 📂 Project Files

| File | Description |
|---|---|
| `Zepto_analysis.sql` | SQL table creation, data exploration, cleaning, and analysis queries |
| `zepto_v2.csv` | Zepto product dataset |
| `README.md` | Project documentation |

## 🔍 Data Exploration

The project explores:

- Number of products
- Null values
- Different product categories
- Products in stock vs out of stock
- Products with multiple SKUs

## 🧹 Data Cleaning

The project performs:

- Identification of products with zero prices
- Removal of records with zero MRP
- Conversion of prices from paise to rupees
